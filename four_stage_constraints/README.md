## 🔥 TL;DR - 立即开始
> **目标**：5分钟掌握四阶段工程化约束原则系统，确保AI协作执行的标准化和一致性
> 
> **行动**：1. 理解阶段原则系统定位 → 2. 选择对应阶段原则文件 → 3. 遵循AI协作执行标准 → 4. 保证贯通流程质量

## 🎯 阶段原则系统定位

### 核心使命
**四阶段工程化约束原则系统**是SPEC_PRACTICAL_GUIDANCE的**双核心支撑体系**之一，与`_framework_guided/`框架指导系统协同工作，为四阶段贯通流程提供完整的方法论支撑。

### 系统特色
- **工程化约束标准**：每个阶段都有严格的工程化约束原则，确保质量和一致性
- **AI协作执行指导**：统一的AI协作执行框架，保证不同阶段的AI协作一致性
- **贯通流程导向**：所有约束都服务于"前阶段输出=后阶段输入"的严格依赖关系
- **实战执行优化**：基于实际项目经验优化的约束原则，确保可执行性

## 📁 文件系统架构

### 四阶段工程化约束文件（4个文件）

| 文件名 | 阶段定位 | 核心职责 | TDD角色 |
|--------|----------|----------|---------|
| **STAGE_REQUIREMENTS_PRINCIPLES.md** | 需求澄清 | 业务需求理解和验收标准定义 | 测什么（可测试性） |
| **STAGE_DESIGN_PRINCIPLES.md** | 设计文档 | 技术架构设计和可测试性准备 | 怎么测（测试策略） |

### 文件内容统一结构
每个阶段原则文件都包含以下标准化部分：
- **🔥 TL;DR** - 立即开始指导

- **核心约束原则** - 该阶段的具体工程化约束要求
- **格式标准原则** - 统一的文档格式和结构要求
- **质量门禁原则** - 质量检查和验证机制
- **🤖 AI协作执行指导** - 基于实战提示词的具体执行约束
- **输出目标与格式原则** - 明确的输出要求和对接标准

## ⚡ 核心设计理念

### 🔄 贯通流程导向约束
**核心洞察**：每个阶段的约束都必须服务于贯通流程的严格依赖关系

```
需求澄清约束 → 为设计文档提供完整业务理解基础
设计文档约束 → 为实施规划提供完整技术架构基础
实施规划约束 → 为任务规划提供完整测试驱动指导
任务规划约束 → 为TDD代码生产提供完整执行基础
       ↓
  确保"前阶段输出=后阶段输入"的无缝对接
```

### 🧪 TDD四阶段专业分工
**核心原则**：TDD不是贯穿所有阶段，而是有明确的主场和专业分工

- **需求澄清**：验收标准可测试性（关注"测什么"）
- **设计文档**：可测试性架构设计（关注"怎么测"，但不实施TDD）
- **⭐ 实施规划**：TDD主场阶段 - 测试驱动转换专责
- **任务规划**：TDD执行任务规划和验证准备

### 🤖 AI协作执行标准化
**重大突破**：建立了统一的AI协作执行约束框架

#### 四大统一执行支柱：
1. **文件操作约束标准化**：强制文件创建、格式要求、结构验证
2. **交互标准化协议**：固定询问话术、批准标准、修改处理
3. **执行节奏精确控制**：阶段边界控制、质量门禁执行
4. **贯通流程导向协作**：确保AI协作体现严格的前后阶段依赖

## 🚀 使用指南

### 📍 按使用目的选择文件

#### 🔍 **内容创作者**
**目标**：创作符合贯通流程标准的阶段内容
**使用方式**：
1. 确定要创作的阶段内容
2. 阅读对应的`STAGE_[阶段]_PRINCIPLES.md`文件
3. 严格按照约束原则和格式标准创作
4. 使用质量门禁机制验证内容质量

#### 🤖 **AI协作执行**
**目标**：确保AI协作的标准化和一致性
**使用方式**：
1. 在AI协作前阅读相关阶段的原则文件
2. 遵循"🤖 AI协作执行指导"部分的具体约束
3. 执行标准化的交互协议和节奏控制
4. 确保输出符合贯通流程对接要求

#### 📋 **质量验证者**
**目标**：验证内容是否符合工程化约束标准
**使用方式**：
1. 使用各阶段原则文件中的"质量门禁原则"
2. 执行机器可执行的检查清单
3. 验证AI协作执行的标准化程度
4. 确保贯通流程对接的完整性

## ⚠️ 重要约束提醒

### 🔒 强制执行原则
1. **约束不可妥协**：所有阶段原则都是强制性约束，不允许降低标准
2. **AI协作必须标准化**：严格遵循统一的AI协作执行指导框架
3. **贯通流程优先**：任何局部优化都不能破坏整体贯通流程
4. **质量门禁必须执行**：前阶段输出未通过验证绝不进入下一阶段

### 🎯 使用注意事项
- **阶段专注**：只关注当前阶段的约束，不要越界到其他阶段
- **输入输出明确**：确保理解当前阶段的输入来源和输出目标
- **AI协作规范**：严格按照AI协作执行指导进行标准化协作
- **持续改进**：基于实践反馈持续优化约束原则
