## Project Overview

This repository contains research materials and documentation for studying Test-Driven Development (TDD) and Behavior-Driven Development (BDD) in the AI era. It focuses on how AI coding tools can enhance and transform traditional TDD/BDD practices.

## Repository Structure

- `_raw_dr/` - Contains deep research documents analyzing AI-enhanced TDD/BDD from different AI models:
  - `raw_dr_core_info.md` - Core summary of 8 dimensions of AI-era TDD/BDD
  - `raw_dr_tdd_deepseek.md` - DeepSeek's analysis of AI-TDD integration
  - `raw_dr_tdd_gemini.md` - Gemini's perspective on AI-enhanced TDD/BDD
  - `raw_dr_tdd_grok.md` - Grok's analysis of TDD/BDD evolution
  - `raw_dr_tdd_openai.md` - OpenAI's analysis of TDD/BDD transformation

- `_raw_digested/` - (Currently empty) Intended for processed/synthesized content

## Key Concepts

The research focuses on 8 core dimensions of AI-enhanced TDD/BDD:

1. **Specification Discovery** - AI-human collaboration in generating executable specifications
2. **Risk Insight** - AI-driven risk analysis for targeted testing
3. **Instant Flow** - Reducing friction in TDD red-green-refactor cycles
4. **Taste Shaping** - AI understanding and applying team coding standards
5. **Root Cause Analysis** - Deep bug analysis and prevention
6. **Contextual Mentorship** - Real-time, context-aware guidance
7. **Contract Verification** - AI-generated contract testing for microservices
8. **Collective Intelligence** - Organizational knowledge aggregation and sharing
